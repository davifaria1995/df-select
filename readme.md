🚗 DF SELECT — Curadoria de Seminovos

Uma landing page moderna, minimalista e responsiva desenvolvida para uma concessionária de veículos seminovos de alto padrão. O projeto foca em oferecer uma experiência de navegação limpa, direta e transparente, transmitindo confiança e sofisticação.

🎯 Objetivo do Projeto

Este projeto foi desenvolvido para compor meu portfólio como desenvolvedor Front-end, aplicando boas práticas de semântica HTML5, arquitetura CSS moderna e design responsivo (Mobile-First / Adaptive Design).

O foco principal foi criar uma interface de alto impacto visual utilizando apenas tecnologias nativas da web (HTML e CSS puro), garantindo carregamento rápido, acessibilidade e facilidade de manutenção sem dependências pesadas de JavaScript.

**Acesse o projeto online:** https://davifaria1995.github.io/df-select/

✨ Funcionalidades e Destaques Técnicos

Layout Responsivo Completo: Adaptação fluida para desktop, tablets e smartphones, utilizando CSS Grid, Flexbox e Media Queries.

Menu Mobile Nativo: Implementação de navegação mobile interativa utilizando apenas HTML semântico (<details> e <summary>), eliminando a necessidade de scripts externos para abrir/fechar o menu.

Filtro de Busca Inteligente (Sem JS): Formulário de pesquisa de veículos estruturado semanticamente com redirecionamento suave (scroll-behavior: smooth) diretamente para a vitrine de estoque.

Design System Consistente: Uso de variáveis CSS (:root) para gerenciamento centralizado de paleta de cores (--ink, --paper, --lime) e tipografia (Space Grotesk e Manrope).

Vitrine de Estoque: Cards de veículos com micro-interações no hover, tags de destaque e hierarquia clara de informações (preço, ano, quilometragem e câmbio).

🛠️ Tecnologias Utilizadas

HTML5 Semântico: Estruturação com tags apropriadas (<header>, <main>, <section>, <article>, <nav>, <footer>) e atributos de acessibilidade (aria-label).

CSS3 Moderno: Custom Properties (Variáveis), CSS Grid Layout, Flexbox, transições suaves e @layer.

Google Fonts: Tipografias Space Grotesk (títulos e destaques) e Manrope (leitura e corpo de texto).

🚀 Como Executar o Projeto

Como o projeto foi construído com tecnologias web puras, não há necessidade de instalar dependências ou configurar servidores complexos:

Clone este repositório:

git clone https://github.com/davifaria1995/df-select.git


Acesse a pasta do projeto:

cd df-select/front-end


Abra o arquivo index.html diretamente no seu navegador de preferência (ou utilize a extensão Live Server no VS Code).
